Shop & vendor foot traffic — pass-bys

A pass-by = a map crossing a vendor's 15-metre frontage. It is a reach number (how many people walked the vendor's face), not a sales number — the currency behind the map's advertising value.

Facilities — do you have enough?

Potty used = a device dwelling ≥ 2 minutes inside a restroom geofence. First-aid visit = a device dwelling ≥ 3 minutes inside a first-aid geofence. Peak-hour demand is compared to each cluster's serviceable throughput to flag where to add units before the rush.

How these numbers are made

The StageFill map runs on phone, tablet, and computer with no app-store install and no signal required. Every open session reports, on-device, which Platz geofence it sits in. We count distinct devices per Platz per hour (never identities — no personal data leaves the phone). Dwell rules translate presence into events: ≥2 min in a restroom = a potty use; ≥3 min at first aid = a visit; a 15 m frontage crossing = a vendor pass-by; presence inside a stage geofence during its set = act draw. Figures on this page are a synthetic sample sized to a realistic pilot day to illustrate the report ArtsQuest receives each morning.
